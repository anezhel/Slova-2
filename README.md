# vocca — слова каждый день

Приложение для iPhone: английский (США) и латышский, уровни A1–B2, интерфейс на русском и украинском.
Английский: 3038 слов, 113 неправильных глаголов, 254 фразовых глагола, 194 слова с синонимами и антонимами. Латышский: 208 слов.
Это веб-приложение (PWA): оно открывается с экрана «Домой» как обычное приложение и работает без интернета. Весь прогресс хранится на телефоне.

## Выложить на GitHub (один раз, минут 5)

1. Зайдите на [github.com](https://github.com) и войдите (или создайте аккаунт).
2. Справа вверху «+» → **New repository**. Название: `vocca`. Видимость: **Public** — бесплатный GitHub Pages работает только с публичными репозиториями. Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file** (или **Add file → Upload files**).
4. Распакуйте архив `vocca.zip`, откройте папку `vocca`, выделите **всё её содержимое** (⌘A) и перетащите в окно браузера. Перетаскивайте содержимое, а не саму папку: файл `index.html` должен оказаться в корне репозитория.
5. Внизу нажмите **Commit changes** и дождитесь загрузки.
6. **Settings → Pages → Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**.
7. Через 1–2 минуты на этой же странице появится адрес вида `https://ВАШ-ЛОГИН.github.io/vocca/`.

## Поставить на iPhone

1. Откройте этот адрес в **Safari**.
2. Нажмите «Поделиться» (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Запускайте vocca с экрана «Домой»: приложение откроется на весь экран и будет работать без интернета.

Прогресс хранится только на этом iPhone. Раз в несколько недель сохраняйте копию: **Настройки → Резервная копия → Сохранить копию прогресса → Сохранить в «Файлы»**. Если удалить vocca с экрана «Домой», прогресс удалится вместе с ним — восстановить его можно из копии.

## Обновить

- Загрузите изменённые файлы в репозиторий поверх старых (**Add file → Upload files**, те же имена и папки). Через минуту-две сайт обновится, а на iPhone новая версия подхватится при следующем запуске (иногда приложение нужно закрыть и открыть ещё раз).
- После правок в коде запустите `python3 tools/make-sw.py` — он обновляет список файлов для работы без интернета.

## Что где менять — дизайн отдельно от функций

| Что нужно | Где |
|---|---|
| Сменить стиль: Festival или Classic | `src/config.js` → `theme` |
| Цвета, шрифты, стекло, тени | Figma (коллекция Theme) → `tools/figma-tokens.json` → `python3 tools/gen-tokens.py` → `src/theme/tokens.css` |
| Вид компонента (кнопки, карточки, меню) | `src/theme/components.css` — только токены, без цветов |
| Пункты настроек: добавить, убрать, переставить | `src/settings/blocks.js` — одна строка на пункт |
| Тексты интерфейса | `src/i18n/ru.js`, `src/i18n/uk.js` |
| Слова | `src/content/en-US/words.tsv`, `src/content/lv/words.tsv` — таблицы, открываются в Numbers и Excel |
| Неправильные глаголы | `src/content/en-US/verbs.tsv` |
| Фразовые глаголы | `src/content/en-US/phrasal.tsv` |
| Синонимы и антонимы | `src/content/en-US/syn.tsv` |
| Новая группа для другого языка | её таблица в папке языка + строка `files` в `pack.js` (группа без таблицы не показывается) |
| Новый язык для изучения | новая папка в `src/content` (`pack.js` + `words.tsv`) и одна строка в `src/content/index.js` |
| Новый язык интерфейса | файл в `src/i18n` + строка в `src/i18n/index.js` и `src/config.js` |
| Слов в день, пауза на ответ, размер тренажёра | `src/config.js` (саму паузу можно выключить в приложении: «Настройки → Отвечать вслух») |

## Как устроено

- `index.html` — оболочка, `src/main.js` — запуск, `src/app.js` — переходы между экранами.
- `src/screens` — экраны 01–12 из Figma, «Слова по темам», `groups.js` — «Фразовые глаголы» и «Синонимы и антонимы» с тренажёрами.
- `src/ui/kit.js` — компоненты, по одному на компонент Figma.
- `src/core` — логика: `store` (прогресс на телефоне), `srs` (лестница интервалов 5 с … 4 мес), `session` (план на день, урок, тренажёр), `groups` (фразовые глаголы и синонимы: интервалы и варианты ответов), `stats`, `tts` (озвучка голосами телефона), `backup`.
- `lib/preact-htm.js` — библиотека интерфейса; сборка не нужна, файлы работают как есть.
- `fonts` — Manrope (Festival) и Onest (Classic). Транскрипции набраны системным шрифтом: в Manrope и Onest нет знаков IPA.
- `sw.js` — кэш для работы без интернета (его пишет `tools/make-sw.py`).
- `tools` — скрипты для разработчика; телефону они не нужны.

## Таблицы слов

Столбцы `words.tsv`: `word`, `ipa` (американская транскрипция, без косых черт), `pos` (noun, verb, adj, adv, phr…), `level` (A1–B2), `topic` (список тем — в `src/content/topics.js`), `ru`, `uk`, `example`, `example_ru`, `example_uk`. Разделитель — табуляция, строка с `#` в начале — комментарий.
Прогресс привязан к слову из столбца `word`: если переименовать слово, его прогресс начнётся заново.

В `verbs.tsv` есть столбцы `group` (тип подсказки), `fakes` (неверные варианты для тренажёра через запятую) и `note` / `note_uk` (пояснение).

`phrasal.tsv`: `phrasal` (например `give up` — первое слово глагол, остальное частица), `level`, `ru`, `uk`, `example` (фразовый глагол в [квадратных скобках] — в тренажёре это место скрыто: `I'll [pick] you [up] at six.`), `example_ru`, `example_uk`, `note` / `note_uk`.

`syn.tsv`: `word`, `pos`, `level`, `syn` (синоним), `ant` (антоним), `ru` / `uk` (перевод слова), `syn_ru` / `syn_uk`, `ant_ru` / `ant_uk`. Неверные варианты тренажёр подбирает сам из этой же таблицы и не предлагает слова, близкие по смыслу к правильному ответу; слова одного смыслового гнезда стоит связывать через синоним (`wonderful` ≈ `great`).

В `words.tsv` внутри уровня слова идут в порядке изучения: сначала первые 290, потом остальные от самых частотных.

Латышские переводы и примеры — черновик: их стоит проверить с носителем языка.
